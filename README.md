# Voice Desk

Voice Desk é a engenharia reversa (REA) do Voice LNK, para uso tanto em Mac quanto em Windows.

Produto construído pelo Time de Engenharia no Multica.

## Documentação
- `AGENTS.md` — como rodar, testar e convenções (completado pelo Arquiteto)
- `docs/produto/` — resumo e PRD
- `docs/design/` — design e protótipo
- `docs/arquitetura/` — arquitetura e deploy em dev
- `docs/retros/` — retrospectivas por épico
- `docs/painel/` — painel de acompanhamento (abra `docs/painel/index.html`)

## Fluxo
Código entra por branch + PR com a chave do card no título. Documentos de planejamento vão direto na `main`.
